# Contributing to Multi-Agent Project

We appreciate your interest in contributing! By participating in this project, you agree to abide by our code of conduct and follow these guidelines.

## How to Contribute

1. **Fork the repository**
   Click the *Fork* button at the top right of the repository page.

2. **Create a feature branch**
   ```bash
   git checkout -b feature/your-feature-name
   ```

3. **Make your changes**
   - Follow the existing code style (PEP 8 for Python).
   - Write clear, concise commit messages.
   - Add or update tests as appropriate.

4. **Run the test suite**
   ```bash
   pytest
   ```
   Ensure all tests pass before committing.

5. **Commit and push**
   ```bash
   git add .
   git commit -m "feat: brief description of your change"
   git push origin feature/your-feature-name
   ```

6. **Open a Pull Request**
   - Navigate to your fork on GitHub.
   - Click *Pull request* and select the `doc-update` branch as the source.
   - Provide a clear description of the changes and reference any related issues.

## Code of Conduct

Please read and follow our [CODE_OF_CONDUCT](CODE_OF_CONDUCT.md) to ensure a welcoming and inclusive environment.

## Reporting Issues

If you encounter a bug or have a feature request, please open an issue with a descriptive title and detailed information.
